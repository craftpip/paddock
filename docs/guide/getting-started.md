# Getting Started

Paddock is one web page where you run all your AI helpers. Each helper is called a PAD. You create a PAD, open it, and talk to it — that's the whole idea.

## What you need

- Paddock open in your browser (ask the person who set it up for the address).
- A login, unless login is turned off. If there is no login screen, you are already in.

## Your first PAD in 3 steps

1. Click **+ Agent** in the top bar.
2. Type a name, for example `my-helper`. Pick the kind of helper (openclaw, opencode, and others — if unsure, leave the default).
3. Click **Create my agent** and wait for the log to say it is done. Then click **Go to Agents** and open your new PAD.

That's it. Your helper is running inside its own box and you can talk to it from the Commands tab.

## What to try next

- **Talk to it** — the Commands tab has buttons that run common tasks. Read [Your PADs](agents.md) next.
- **Type commands yourself** — open the terminal at the bottom of the agent page. See [The terminal](terminal.md).
- **Put it on the web** — some helpers have a built-in web page you can publish. See [Sharing on the web](web-publish.md).
- **Keep secrets safe** — API keys and tokens go in the Vault, never in chat. See [Keeping secrets](vault.md).
